安装

Aureole 1.1.0 的安装包是 AureoleSetup-1.1.0.exe，14.4 MB。系统要求是 64 位 Windows 10（1809 或更新）或 Windows 11。

  1. 双击安装包。向导会先问安装位置，默认是 %LOCALAPPDATA%\Programs\Aureole。
  2. 按默认方式安装时不需要管理员权限，不会弹 UAC。只有选择“为所有用户安装”时才需要。
  3. 安装完成后从开始菜单启动 Aureole。
安装包没有代码签名。如果 Windows 显示“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。

卸载

打开“设置 → 应用 → 已安装的应用”，找到 Aureole，选择卸载。卸载会删除程序文件和安装时写入的右键菜单、文件关联；你的代码文件不会被删除。

第一次打开

首次启动会看到欢迎页，上面有新建文件、打开文件、打开文件夹三个按钮，以及最近打开过的文件列表。

  • 点“打开文件夹”，选一个 Python 项目。左侧资源管理器会列出里面的文件，点文件名即可在新标签页打开。
  • Ctrl+S 保存，Ctrl+Shift+S 另存为。标签页标题前的圆点表示有未保存的修改。
  • 底部状态栏显示行号、列号、编码（默认 UTF-8）、缩进方式（空格或制表符）和当前语言。
  • 默认会恢复上次关闭时打开的文件。不需要的话，在设置 → 常规里关掉“启动时恢复打开的文件”。
  • 从资源管理器双击文件时，文件会交给已经运行的窗口，不会再多开一个 Aureole。

设置

按 Ctrl+, 打开设置。左侧是分类，顶部有搜索框，直接输入“字号”或“缩进”就能定位到对应项。

分类内容
常规界面语言（重启后生效）、启动时恢复打开的文件、崩溃恢复快照及间隔（10 到 120 秒，默认 20 秒）
外观配色主题（Midnight、Monokai、Daylight）、编辑器字体
编辑器字号、缩进宽度（2/4/8 空格）、Tab 插入空格、自动换行、显示缩略图、高亮当前行、缩进参考线、自动闭合括号和引号、光标宽度
文件保存时删除行尾空格、保存时补最后一个换行、最近文件数量上限（设为 0 关闭）
终端终端字号、回滚行数
资源管理器文件夹右键菜单、默认文件关联、Aureole 文件图标

除界面语言外，所有设置改完立即生效，不需要重启程序。

运行与调试

运行和调试都调用系统的 python，所以先确认它已经加入 PATH。打开内置终端，输入：

python --version

能显示版本号就可以继续。提示“不是内部或外部命令”，说明需要重新安装 Python 并勾选“Add Python to PATH”。

运行

按 Ctrl+F5，编辑器会先保存当前文件，再在终端里执行 python -u "文件路径"。输出直接显示在内置终端里，按 Shift+F5 结束运行。

调试

按 F9 在光标所在行设置断点，再按 F5 启动调试。Aureole 调用的是标准库的 pdb，断点会在调试开始后自动下发，程序停在断点处。

  • F5 继续运行到下一个断点。
  • F10 单步跳过，F11 单步进入，Shift+F11 跳出当前函数。
  • 终端里可以直接输入 pdb 命令，例如 p x 查看变量、l 查看附近代码、q 退出。
  • 调试期间编辑代码不会热更新，修改后需要停止并重新启动调试。
目前只支持对当前标签页里的 Python 文件运行和调试。未保存的新文件会先提示保存。

内置终端

按 Ctrl+` 打开或收起终端。启动的是 PowerShell，工作目录就是你当前打开的文件夹，所以可以直接运行 git status、pip install 之类的命令。

  • “运行”菜单里有“清空终端”，只清屏，不结束当前进程。
  • 按 Ctrl+F5 运行脚本时，编辑器复用这个终端，输出和你的手动命令在同一个窗口里。
  • 停止运行会结束由这次运行启动的 python 进程树；终端本身继续可用。

右键菜单与文件关联

在设置 → 资源管理器里有三个开关，默认开启：

  • 文件夹右键菜单：在资源管理器中右键任意文件夹，多出“在 Aureole 中打开”。
  • 默认文件关联：让 .py、.md、.json 和常见文本文件默认用 Aureole 打开。
  • Aureole 文件图标：给这些关联类型换成 Aureole 的图标。

开关改完立即写入当前用户的注册表，不需要重启。想恢复原状，把开关关掉即可；卸载时也会清理安装时写入的项。

界面语言

设置 → 常规 → 语言，共有 41 种界面语言。选好后需要重启 Aureole 一次才会应用。

  • 阿拉伯语、希伯来语、波斯语和乌尔都语会自动切换为从右到左的排版。
  • 个别翻译缺项会回退显示英文，不影响使用。
  • 语言只影响界面，不会改变代码文件的编码。

常见问题

按 Ctrl+F5 提示找不到 python

Python 没有加入 PATH。重新运行 Python 安装程序，勾选“Add Python to PATH”，然后关掉 Aureole 再打开，让终端拿到新的环境变量。

Windows 提示“已保护你的电脑”

安装包没有购买代码签名证书。点“更多信息”，再点“仍要运行”即可。下载后可以核对文件大小是否为 14,407,822 字节。

双击 .py 文件还是用记事本打开

到设置 → 资源管理器，打开“默认文件关联”。如果仍然无效，在 Windows 的“设置 → 应用 → 默认应用”里按扩展名指定 Aureole。

改了语言但没有变化

语言在启动时加载，需要完全退出再打开。关闭所有 Aureole 窗口后重新启动即可。

双击文件却开了第二个窗口

1.1.0 起是单实例，第二次启动会把文件交给已运行的窗口。如果仍然多开，检查是否有旧版本仍在运行。

怎么彻底清除 Aureole 的痕迹

先正常卸载，再按需删除 %APPDATA%\Aureole Studio 和注册表项 HKEY_CURRENT_USER\Software\Aureole Studio。这两处只存设置和恢复快照，不存你的项目文件。

有 macOS 或 Linux 版本吗

没有。目前只有 Windows x64 安装包。

Install

The installer is AureoleSetup-1.1.0.exe, 14.4 MB. Aureole runs on 64-bit Windows 10 (1809 or newer) and Windows 11.

  1. Run the installer. The wizard asks for a location; the default is %LOCALAPPDATA%\Programs\Aureole.
  2. Installing for the current user does not need administrator rights and will not trigger a UAC prompt. Only the all-users option does.
  3. Start Aureole from the Start menu when the wizard finishes.
The build is not code-signed. If Windows shows "Windows protected your PC", click More info, then Run anyway.

Uninstall

Open Settings → Apps → Installed apps, find Aureole and choose Uninstall. This removes the program files and the context-menu and file-association entries written during setup. Your source files are left alone.

First run

The welcome page has three buttons (new file, open file, open folder) and a list of recent files.

  • Choose Open Folder and pick a Python project. The Explorer on the left lists the files; click one to open it in a new tab.
  • Ctrl+S saves, Ctrl+Shift+S saves as. A dot before the tab title means there are unsaved changes.
  • The status bar shows the line, column, encoding (UTF-8 by default), indentation mode and the current language.
  • Files that were open at shutdown are restored by default. Turn that off under Settings → General if you prefer a clean start.
  • Opening a file from Explorer passes it to the running window instead of starting a second copy.

Run and debug

Both commands call the system python, so it has to be on PATH. Open the terminal and check:

python --version

If that prints a version, you are set. If Windows reports that python is not recognized, reinstall Python with "Add Python to PATH" checked, then reopen Aureole so the terminal gets the new environment.

Run

Ctrl+F5 saves the current file and runs python -u "path" in the built-in terminal. Output appears there. Shift+F5 stops the run.

Debug

F9 sets a breakpoint on the cursor line, then F5 starts the debugger. Aureole runs the standard library pdb, sends the breakpoints once the prompt appears, and continues to the first one.

  • F5 continues to the next breakpoint.
  • F10 steps over, F11 steps into, Shift+F11 steps out.
  • The terminal accepts pdb commands directly: p x prints a variable, l lists nearby code, q quits.
  • Editing code during a session does not hot-reload it. Stop and start the debugger again after changes.
Run and debug work on the Python file in the current tab. A new unsaved file is saved first.

Terminal

Ctrl+` shows or hides the terminal. It starts PowerShell in the folder you opened, so git status or pip install work without changing directory first.

  • Run → Clear Terminal clears the screen without stopping the shell.
  • When you run a file, the editor reuses this terminal, so output and your own commands share one window.
  • Stopping a run ends the Python process tree started by that run. The terminal itself stays alive.

Context menu and associations

Settings → Explorer has three switches, all on by default:

  • Folder context menu: right-click any folder in Explorer and choose "Open in Aureole".
  • Default file associations: open .py, .md, .json and common text files with Aureole by default.
  • Aureole file icons: use Aureole icons for those types.

Changes are written to the current user's registry immediately. Turn a switch off to revert it. Uninstalling also removes the entries created during setup.

Interface language

Settings → General → Language lists 41 interface languages. Restart Aureole once after changing it.

  • Arabic, Hebrew, Persian and Urdu switch the layout to right-to-left automatically.
  • Missing translation keys fall back to English. Nothing breaks.
  • The language setting only affects the interface, not the encoding of your files.

FAQ

Ctrl+F5 says python was not found

Python is not on PATH. Run the Python installer again, tick "Add Python to PATH", then close and reopen Aureole so the terminal picks up the new environment.

Windows says it protected my PC

The installer has no code-signing certificate. Click More info, then Run anyway. You can check the download is complete: the file should be exactly 14,407,822 bytes.

.py files still open in Notepad

Go to Settings → Explorer and enable default file associations. If Windows still ignores it, set Aureole per extension under Settings → Apps → Default apps.

I changed the language but nothing happened

The language is loaded at startup. Quit all Aureole windows and open it again.

Opening a file started a second window

Version 1.1.0 is single-instance: a second launch hands the file to the running window. If you still get two windows, an older build may be running.

How do I remove every trace

Uninstall normally, then optionally delete %APPDATA%\Aureole Studio and the registry key HKEY_CURRENT_USER\Software\Aureole Studio. Those hold settings and recovery snapshots only, never your project files.

Is there a macOS or Linux build

No. The only package right now is the Windows x64 installer.
